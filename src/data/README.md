# Dữ liệu tĩnh (src/data)

| File | Là dữ liệu gì |
|---|---|
| `products.ts` | **Sản phẩm** (tên, giá, quy cách, ảnh) — admin sửa sản phẩm sẽ ghi vào đây |
| `combos.ts` | Combo |
| `banners.ts`, `brand-showcase.ts`, `brands.ts` | Banner trang chủ, khối thương hiệu |
| `stores.ts` | Danh sách cửa hàng |
| `homepage-placeholders.ts`, `product-detail-placeholders.ts` | Dữ liệu mẫu cho khối chưa có nghiệp vụ thật |
| `product-detail-content.ts` | Nội dung chữ trên trang chi tiết sản phẩm |
| `vietnam-addresses.ts` | Tỉnh / quận / phường cho ô chọn địa chỉ |
| `vietnam-streets.ts` | Tọa độ tuyến đường chính (gợi ý địa chỉ dự phòng) |
| `hcm-admin-units-2025.ts` | Phường / xã TP.HCM sau sắp xếp 01/07/2025 (tự sinh, không sửa tay) |
| `hcm-street-segments.ts` | Đoạn đường trùng tên ở nhiều quận (tự sinh từ OSM, không sửa tay) |
| `products_test.ts` | Dữ liệu thử |
