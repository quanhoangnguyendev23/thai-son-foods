# Cấu hình và cờ bật / tắt tính năng (src/config)

| File | Điều chỉnh gì |
|---|---|
| `features.ts` | Cờ bật / tắt các tính năng chưa chốt (mặc định tắt) |
| `homepage.ts` | Chọn trang chủ mới / cũ và các khối trên trang chủ |
| `product-detail.ts` | Bật / tắt các khối trên trang chi tiết sản phẩm |
| `inventory.ts` | **Kho và giao hàng**: phí ship theo km, bán kính giao tối đa, thời gian giữ chỗ |
| `inventorySheet.ts` | Nguồn tồn kho Google Sheet (mặc định nhập tay trên web) |
| `service-area.ts` | Phạm vi phục vụ (hiện chỉ TP.HCM) |
| `legal.ts` | Thông tin pháp lý ở chân trang |
| `membership.ts` | Hội viên, giao định kỳ |
| `partner.ts` | Đối tác / CTV, hoa hồng |
| `bannedWords.ts` | Từ cấm trong đánh giá |
